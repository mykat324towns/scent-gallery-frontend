# Brand Assets

Visual assets for Scent Gallery used across workflows — ad creative, content, site design, and more.

## Structure

| Folder | Contents |
|--------|---------|
| `logos/` | Scent Gallery logo files (primary, secondary, icon, dark/light variants) |
| `headshots/` | Jaxson's headshots and personal brand photos |
| `other/` | Product shots, lifestyle imagery, brand textures, and anything else |

## Usage

When building creative, generating content, or designing anything Scent Gallery-related, pull assets from here first. Drop new assets into the appropriate subfolder as they come in.
